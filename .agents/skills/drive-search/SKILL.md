# Google Drive 検索・閲覧スキル（ブラウザ経由）

ChromeのGoogle DriveをブラウザMCPで操作してファイルを検索・閲覧する。
読み取り専用。ファイルの作成・編集はユーザーが行う。

## 前提条件

- ChromeがGoogleアカウントにログイン済みであること
- `/browser` コマンドが有効であること

## 実行手順

### Step 1: 検索先を特定する

**サービス座標がある場合（推奨）**:
- `memory/projects/{name}/overview.md` の Drive フォルダ URL を使用
- そのURLに直接アクセスして目的のファイルを探す

**サービス座標がない場合**:
- Drive 全体を検索する（遅くなる可能性あり）
- 検索後、フォルダURLをサービス座標として記録することを提案する

### Step 2: ブラウザで検索・アクセスする

1. `/browser` でブラウザを起動
2. サービス座標のURLに直接アクセス、またはDrive検索を実行する
3. 対象ファイル・フォルダを特定する

### Step 3: ファイル内容を読み取る

**Google Docsの場合**: ドキュメントを開いてテキストを読み取る
**Google Sheetsの場合**: スプレッドシートを開いて対象シート・セル範囲を読み取る
**フォルダの場合**: ファイル一覧を取得して構造を把握する

### Step 4: 結果を整理して提示する

**ファイル検索結果**:
```markdown
## Drive 検索結果：{検索条件}

**検索先**: {フォルダ名または「Drive全体」}

| ファイル名 | 種別 | 最終更新 | URL |
|---|---|---|---|
| {名前} | Doc/Sheet/PDF | {日付} | [リンク]({URL}) |

**見つからなかった場合**: {代替案・確認事項}
```

**ドキュメント内容の場合**:
```markdown
## ドキュメント概要：{ファイル名}

**最終更新**: {日付}
**作成者**: {作成者}

### 主要な内容
{要点を箇条書きで}

### 関連する注意点
{ユーザーの依頼に関連する部分を抜粋}
```

### Step 5: ファイリングを提案する

重要な情報が含まれていた場合：
```
このドキュメントの内容を memory/projects/{name}/context/{topic}.md に記録しますか？
```

## 注意事項

- ファイルの編集・削除・共有設定変更はしない（読み取り専用）
- 機密情報を含むファイルの内容は要約して提示し、全文を記録しない
- ファイルのURLはサービス座標として積極的に `overview.md` に記録を提案する
- Drive検索は時間がかかる場合があるため、サービス座標での直接アクセスを優先する
