# 専門家補充スキル

チームに不在の専門家が必要になったとき、新しい専門家エージェントを追加するプロセス。

## 実行手順

### Step 1: 不足を確認する

`memory/team/roster.md` を参照して：
- 必要な専門分野がチームにあるか
- 在籍しているが能力が不足していないか

### Step 2: 必要な専門家の要件を定義する

```markdown
## 補充要件

**専門分野**: {何の専門家が必要か}
**必要な背景知識**: {業界知識・資格・経験}
**担当するタスクの例**:
- {タスク例1}
- {タスク例2}
**呼び出し頻度の予測**: 高/中/低
```

### Step 3: ユーザーに提案する

```
## 専門家の補充提案

現在の秘書チームに **{専門分野}の専門家** がいません。

**必要な背景**:
{なぜ必要か}

**新しい専門家の概要**:
- 名前: {agent-name}（例: legal-agent, finance-agent）
- 専門知識: {知識・フレームワーク・資格}
- 担当タスク: {主に担当するタスク}

▶ この専門家をチームに追加してよいですか？
```

### Step 4: 承認後にエージェントを作成する

承認が得られたら以下のファイルを作成する：

1. `.agents/plugins/{name}-agent/plugin.json`
2. `.agents/plugins/{name}-agent/rules/persona.md`（専門家ペルソナ定義）
3. `.agents/plugins/{name}-agent/skills/{domain}-review/SKILL.md`（専門分野のレビュースキル）

### Step 5: ロスターを更新する

`memory/team/roster.md` に新メンバーを追加する。

## 専門家ペルソナのテンプレート

```markdown
---
description: {専門家名}のペルソナ・専門知識・思考フレームワーク。常時適用。
alwaysApply: true
---

# {専門家名}（{英語名}）── ペルソナ

あなたは{専門分野}の専門家秘書です。
{資格・経験の設定}を持ち、{思考の特徴}から物事を見ます。

## 専門知識

- {知識領域1}
- {知識領域2}

## 思考フレームワーク

{専門家特有の分析手法・フレームワーク}

## アウトプットの特徴

- {観点1}: {どんな切り口で回答するか}
- {観点2}

## 限界と隣接領域

{この専門家が答えられないこと・他の専門家に委ねるべきこと}
```
