# ドライブ検索・閲覧スキル（手段非依存）

ファイルを検索・閲覧し、要点を整理して提示する。読み取り専用。作成・編集・共有設定の変更は
`memory/delegation.md` に従い事前提示→承認を経る（本スキルの範囲外）。

## 実行手順

### Step 1: 検索先を特定する

**サービス座標がある場合（推奨）**:
- `memory/projects/{name}/overview.md` の Drive フォルダ URL／ID を使い、そこから直接探す

**サービス座標がない場合**:
- ドライブ全体を検索する（遅くなる可能性あり）
- 見つかったらフォルダ URL をサービス座標として `overview.md` に記録することを提案する

### Step 2: 手段を解決する（`memory/service-capabilities.md` の解決順）

1. **コネクタ／MCP**：セッションにドライブ系ツール（例：`search_files` / `read_file_content` /
   `get_file_metadata` を持つサーバー）があればそれを使う。座標があればフォルダ指定で検索する
2. **ブラウザ操作**：環境が対応していれば座標の URL（または `https://drive.google.com`）を開いて
   検索・閲覧する
3. **手動アシスト**：上記が無ければ座標から URL を提示し、「開いて該当部分を貼り付けてください」と依頼する

### Step 3: ファイル内容を読み取る

- **ドキュメント**：本文テキストを読み取り、依頼に関連する部分を抽出する
- **スプレッドシート**：対象シート・セル範囲を特定して読み取る
- **フォルダ**：ファイル一覧を取得して構造を把握する

### Step 4: 結果を整理して提示する

**ファイル検索結果**:
```markdown
## 検索結果：{検索条件}

**検索先**: {フォルダ名または「全体」}

| ファイル名 | 種別 | 最終更新 | URL |
|---|---|---|---|
| {名前} | Doc/Sheet/PDF | {日付} | [リンク]({URL}) |

**見つからなかった場合**: {代替案・確認事項}
```

**ドキュメント内容の場合**:
```markdown
## ドキュメント概要：{ファイル名}

**最終更新**: {日付}　**作成者**: {作成者}

### 主要な内容
{要点を箇条書きで}

### 依頼に関連する部分
{抜粋・要約}
```

### Step 5: ファイリングを提案する

重要な情報が含まれていた場合：
```
このドキュメントの要点を memory/projects/{name}/context/{topic}.md に記録しますか？（原文は Drive が原本。要点＋リンクのみ）
```

## 注意事項

- ファイルの編集・削除・共有設定変更はしない（読み取り専用）
- 機密情報を含むファイルは要約して提示し、全文を記録しない
- URL はサービス座標として積極的に `overview.md` への記録を提案する
- 全体検索より座標からの直接アクセスを優先する
