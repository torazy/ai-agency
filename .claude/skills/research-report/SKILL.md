# リサーチ・レポートスキル

Brave SearchのMCPツールを使ってWebを調査し、構造化されたリサーチレポートを作成する。

## 使用するMCPツール

- `brave_web_search`: Web検索
- `brave_local_search`: ローカル情報検索（必要な場合）

## 実行手順

### Step 1: リサーチ範囲を定義する

ユーザーの依頼から以下を特定する：

- **リサーチのゴール**: 何を知りたいのか
- **対象領域**: 技術 / 市場 / 競合 / 法規制 / その他
- **深さ**: 概要把握 / 詳細調査 / 意思決定のための比較
- **期限感**: 今すぐ / 今日中 / 今週中

### Step 2: 検索クエリを組み立てる

効果的な検索のために：
- 英語と日本語の両方で検索する（特に技術情報）
- 公式ドキュメント・事例・比較記事の順で検索する
- 情報の鮮度が重要な場合は期間を指定する（`after:2024`など）

最低3回の検索を実施して情報を多角的に収集する。

### Step 3: 情報を整理・評価する

収集した情報を以下の観点で評価する：

- **信頼性**: 公式サイト・著名な情報源か
- **鮮度**: いつの情報か
- **関連性**: ユーザーのニーズに合致するか

矛盾する情報がある場合は両方を提示し、どちらが信頼できそうかを補足する。

### Step 4: レポートを作成する

```markdown
# リサーチレポート：{テーマ}

**調査日**: {日付}
**調査目的**: {ゴール}

---

## エグゼクティブサマリー

（3〜5行で要点をまとめる）

## 主要な発見事項

### 1. {発見事項1}
（根拠・情報源を含めて説明）

### 2. {発見事項2}

### 3. {発見事項3}

## 比較・評価（オプション）

| 項目 | 選択肢A | 選択肢B | 選択肢C |
|---|---|---|---|
| {観点1} | | | |
| {観点2} | | | |

## 推奨・示唆

（発見事項からどんな行動を取るべきか）

## 情報源

- [{タイトル}]({URL})
- [{タイトル}]({URL})

## 不確かな点・追加調査が必要な点

- （信頼性が低い情報・情報不足の領域）
```

### Step 5: ファイリングを提案する

```
このリサーチ結果を `memory/projects/{name}/context/{topic}.md` に保存しますか？
```

## 注意事項

- 検索結果を直接コピーペーストしない（要約・構造化して提示）
- 情報源URLは必ず記載する
- 不確かな情報には「〜と報告されています」「〜の可能性があります」と明記
- 法的・医療・財務アドバイスが必要な領域は専門家への相談を促す
