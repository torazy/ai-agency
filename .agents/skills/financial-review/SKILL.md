# 財務レビュースキル

あらゆる提案・計画を財務の観点から分析し、リスクとROIを明示する。

## 実行手順

### Step 1: コスト構造を分解する

```markdown
## コスト分析

### 初期費用
| 項目 | 金額 | 根拠 |
|---|---|---|
| {項目} | {金額} | {根拠・仮定} |
| **合計** | {合計} | |

### 運用費用（月次/年次）
| 項目 | 月額 | 年額 | 根拠 |
|---|---|---|---|
| {項目} | {金額} | {金額} | {根拠} |
| **合計** | {月額合計} | {年額合計} | |

### 隠れたコスト・見落としがちな費用
- {学習コスト・導入工数など}
- {移行コスト}
- {機会損失}
```

### Step 2: ROI・回収期間を計算する

```markdown
## ROI分析

**期待する効果（定量）**:
- {削減効果・売上増など}: 月額 {金額}

**投資回収期間**: 初期費用 ÷ 月次効果 = {X}ヶ月

**ROI（1年）**: （年次効果 - 年次費用） ÷ 初期費用 × 100 = {X}%

**NPV（3年間、割引率X%）**: {計算可能な場合}
```

### Step 3: 代替案とのコスト比較

```markdown
## 代替案比較

| 案 | 初期費用 | 年間運用費 | ROI（1年） | 推奨度 |
|---|---|---|---|---|
| 現状維持 | 0 | {現状コスト} | 0% | |
| 案A（提案中）| {金額} | {金額} | {%} | |
| 案B（代替） | {金額} | {金額} | {%} | |
```

### Step 4: 財務的リスクを評価する

```markdown
## 財務リスク

| リスク | 発生確率 | 損失規模 | 対策 |
|---|---|---|---|
| {リスク} | 高/中/低 | {金額規模} | {対策} |
```

### Step 5: 財務的観点の結論を出す

```markdown
## 財務的結論

**推奨**: {Go / No-Go / 条件付きGo}

**理由**:
{ROI・コスト構造に基づく明確な根拠}

**条件（条件付きGoの場合）**:
{この条件が満たされれば進めてよい}

**前提条件・仮定**:
{計算に使った仮定。実際と乖離した場合に結論が変わりうる点}
```

## 注意事項

- 数字は根拠（公開情報・相場・ユーザー提供情報）と一緒に提示する
- 不明な数字は仮定値として明示し、感度分析を行う
- 税効果・補助金は「考慮可能性あり」として言及するが詳細は専門家へ委ねる
