# 能力拡張（自己成長）スキル

新しいサービスや機能への対応を、3段階のレベルで実現するプロセス。

## 実行手順

### Step 1: 現在の対応状況を確認する

`memory/service-capabilities.md` を読み込み、要求されたサービスが：
- **稼働中**: 対応するスキルをそのまま使用
- **未対応**: 以下のステップへ進む

### Step 2: 対応レベルを判定する

| Level | 判定基準 | 対応方針 |
|---|---|---|
| 1 | ブラウザでアクセス可能（ログイン済みのChromeから操作できる） | 軽い確認後、ブラウザスキルを自律作成 |
| 2 | コミュニティMCPが存在する（npmやPyPIで入手可能） | 設定内容を提示して承認を得る |
| 3 | カスタム実装が必要（API仕様書が必要・認証が複雑） | 要件・工数・選択肢を整理して判断を仰ぐ |

**判定に使う情報**:
- サービス名からブラウザアクセス可能か推測する（一般的なWebサービスならLevel 1候補）
- `memory/insights.md` に過去の試行記録があれば参照する

### Step 3-L1: Level 1 ── ブラウザスキルの自律作成

以下の内容でユーザーに提示する：

```
## 新しいサービスへの対応方法

**{サービス名}** はブラウザ経由で操作できます。

**作成するスキルの概要**:
- スキル名: {service-name}-browser
- 操作: {想定する操作（読み取り / 検索 / 書き込み）}
- 前提: Chromeが {サービス名} にログイン済みであること

▶ このスキルを作成してよいですか？
```

承認後、スキルファイルを作成する：
- パス: `.agents/skills/{service-name}-browser/SKILL.md`（Antigravity は `.agents/skills/` を自動認識する）
- `memory/service-capabilities.md` の稼働中テーブルに追記する

### Step 3-L2: Level 2 ── コミュニティMCPの追加

以下の内容でユーザーに提示する：

```
## 新しいサービスへの対応方法

**{サービス名}** はコミュニティMCPで対応できます。

**追加する設定**:
\`\`\`json
{
  "mcpServers": {
    "{service-name}": {
      "command": "...",
      "args": [...],
      "env": {
        "{ENV_VAR}": "（設定が必要）"
      }
    }
  }
}
\`\`\`

**必要な準備**:
1. {手順1}
2. {手順2}

▶ この設定を `mcp_config.json` に追加してよいですか？
```

承認後、IDEのMCPストアまたは `~/.gemini/config/mcp_config.json` に設定を追加し（構成記録として `tools/mcp_config.sample.json` も更新）、`service-capabilities.md` に追記する。

### Step 3-L3: Level 3 ── カスタム実装の提案

以下の内容でユーザーに提示する：

```
## 新しいサービスへの対応方法

**{サービス名}** はカスタム実装が必要です。

**状況**:
（なぜ Level 1/2 で対応できないのか）

**選択肢**:

**A) カスタムMCPサーバーを構築する**
- 工数: 数時間〜1日程度
- 必要なもの: {サービス名}のAPIキー、Python環境
- できること: {機能リスト}

**B) ブラウザ操作で代替する（制限あり）**
- 工数: 30分程度
- 制限: {できないこと}

**C) 今回は手動で対応する**
- 私が手順を案内します

どの方針で進めますか？
```

### Step 4: 完了後に記録を更新する

スキル・MCP追加後、必ず以下を実行する：

1. `memory/service-capabilities.md` の「稼働中」テーブルを更新
2. `memory/insights.md` に学習内容を記録
3. （Level 1）`.agents/skills/` に置けば Antigravity が自動認識するため追加登録は不要

## 参考：ブラウザスキルのテンプレート

Level 1 で作成するスキルの基本構造：

```markdown
---
name: {service-name}-browser
description: {サービス名}にブラウザ経由でアクセスする。{できること}。前提：Chromeが{サービス名}にログイン済みであること。
---

# {サービス名} ブラウザ操作スキル

## 前提条件
- Chromeが {サービス名} にログイン済みであること
- /browser コマンドが有効であること

## 操作手順

### {操作名}
1. {サービスのURL} をブラウザで開く
2. {手順}
3. 結果を読み取って返答する

## 注意事項
- 読み取り専用（書き込みは確認後のみ）
- ページ読み込みに失敗した場合はユーザーに報告する
```
