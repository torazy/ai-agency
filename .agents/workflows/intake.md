# /intake ── 情報ファイリング

ユーザー入力：`/intake <情報>`（または貼り付けたテキスト）

`intake-and-file` スキルの手順に従って実行する。要点：

1. **種類を判定**：会議メモ／決定事項／課題／背景・仕様／関係者／現状／サービス座標／生メモ／ドメイン知識。
   複数混在は分割して複数ファイルへ。
2. **対象プロジェクトを特定**：指示・内容・`GEMINI.md` から。不明ならユーザーに確認。
3. **既存ファイルを読んでから書く**：重複・矛盾を避ける。矛盾時はユーザー確認後に上書き。
   新規作成は `memory/delegation.md` の許可範囲を確認。
4. **構造化して書き込む**：各タイプの書式（`intake-and-file` スキル参照）に従う。
   - 決定事項には必ず **「予測（期待した結果）」と「検証日」** を含める（`/review-decisions` が後で検証する）。
   - 人物ファイル名は `{姓}-{名}-{所属略称}-{役職略称}.md`、一意識別子を必ず記録。
5. **完了報告**：何をどこに（新規/追記/更新）したか＋気づいたこと（未登録の座標等）＋次のアクション候補1つ。

原文をそのままコピーしない（要点を抽出して構造化）。固有名詞・数字・日付は原文のまま維持する。
