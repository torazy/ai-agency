# Slack操作スキル（ブラウザ経由）

ChromeのSlackをブラウザ操作で使用する。
Slack APIは使用しない。/browser コマンドでChromeを操作する。

## 前提条件

- Chromeが開いていてSlackにログイン済みであること
- `/browser` コマンドが有効であること

## 対応できること

- 特定チャンネルの最新メッセージを読む
- Slackbotにメッセージを送信してAIアシスタントに質問する
- ユーザーへのDMを送信する（要確認）
- チャンネルへのメッセージ送信（要確認）

## 実行手順

### チャンネル・DMを読む

1. プロジェクトのSlackチャンネル名を確認する
   - `memory/projects/{name}/overview.md` のサービス座標を参照
2. `/browser` でブラウザを起動
3. `https://app.slack.com/client` を開く（すでに開いている場合はそちらを使用）
4. 対象チャンネルに移動して最新メッセージを読み取る
5. 関連情報をまとめて報告する

### Slackbotに質問する（社内AIアシスタント経由）

1. `/browser` でブラウザを起動
2. Slackbotダイレクトメッセージを開く
3. 質問を入力して送信
4. 回答が返ってきたら読み取って報告する

### メッセージを送信する（要確認）

送信前に必ず内容を提示する：

```
## Slack 送信確認

**宛先**: #{チャンネル名} / @{ユーザー名}
**内容**:
{送信する全文}

▶ この内容で送信してよいですか？
```

承認後にブラウザで送信操作を実行する。

## サービス座標の取得

チャンネル名が不明な場合：
- `memory/projects/{name}/overview.md` を確認
- なければユーザーに確認して記録する

## 注意事項

- ブラウザ操作はリアルタイムの状態に依存するため、エラーが出た場合はユーザーに報告する
- 機密情報を含むチャンネルへのアクセスは慎重に（読み取り内容をログに残さない）
- Slackの操作はChromeのログイン状態に依存するため、セッション切れの場合はユーザーにログインを依頼する
- ブラウザ操作が失敗した場合は、代替として手動手順をガイドする
