# 法務レビュースキル

契約・規約・コンプライアンス事項を法務の観点から分析し、リスクと論点を整理する。
**最終的な法的判断は必ず弁護士へ委ねること。**

## 実行手順

### Step 1: 契約・文書の概要把握

```markdown
## 文書概要

- **文書の種類**: {業務委託契約 / NDA / SaaS利用規約 / 売買契約 / 雇用契約 等}
- **当事者**: 自社（{立場}）← → 相手方（{名称・立場}）
- **対象範囲**: {何についての契約か}
- **契約期間**: {開始日 〜 終了日・自動更新の有無}
- **準拠法**: {日本法 / 外国法}
- **管轄裁判所**: {東京地裁等}
```

### Step 2: リスク条項の洗い出し

```markdown
## リスク条項レビュー

| 条項 | 内容 | リスクレベル | 問題点・懸念 | 修正提案 |
|---|---|---|---|---|
| 損害賠償 | {内容} | 高/中/低 | {上限なし・無制限等} | {上限額の設定を提案} |
| 免責事項 | {内容} | | {相手方のみ免責等} | |
| 解除条件 | {内容} | | {一方的解除権等} | |
| 知的財産権 | {内容} | | {成果物の帰属} | |
| 秘密保持 | {内容} | | {期間・対象範囲} | |
| 下請法リスク | {内容} | | {優越的地位の濫用等} | |
| データ取扱 | {内容} | | {個人情報・GDPR} | |
```

### Step 3: 自社に不利な点の整理

```markdown
## 自社への影響分析

### 高リスク項目（要交渉・要確認）
1. **{条項名}**: {具体的な問題点}
   - リスクシナリオ: {最悪の場合何が起きるか}
   - 修正の方向性: {どう変えるべきか}

### 中リスク項目（交渉の余地あり）
- {条項}: {懸念点と対応方針}

### 低リスク・問題なし
- {問題なしと判断した主要条項}
```

### Step 4: コンプライアンス確認

```markdown
## コンプライアンスチェック

| 法令 | 関連する条項 | 適合性 | 確認事項 |
|---|---|---|---|
| 個人情報保護法 | {条項} | 問題なし/要確認/問題あり | {確認内容} |
| 下請法 | {条項} | | |
| 特定商取引法 | {条項} | | |
| 労働基準法 | {条項} | | |
| 独占禁止法 | {条項} | | |
```

### Step 5: 弁護士への相談論点まとめ

```markdown
## 弁護士相談の論点整理

**相談が必要な理由**: {なぜ専門家確認が必要か}

**確認してほしい論点**:
1. {最重要確認事項}：「{具体的な質問文}」
2. {次点確認事項}：「{質問文}」
3. {その他確認事項}

**必要書類**: {持参・共有が必要なもの}
**緊急度**: {高（署名前に必須）/ 中（近日中）/ 低（参考確認）}
```

### Step 6: 法務観点サマリー

```markdown
## 法務観点の総評

**リスクレベル**: {高 / 中 / 低}

**このまま締結しても良いか**:
- {締結可 / 修正後に締結 / 弁護士確認後に判断 / 締結見送りを検討}

**修正を求めるべき最重要条項**:
{Top 3の条項と修正の方向性}

⚠️ **免責**: これは法的な確定判断ではありません。重要な契約は必ず弁護士にご確認ください。
```

## 注意事項

- **法的確定判断は絶対にしない**。「リスクがある可能性がある」「要確認」の範囲にとどめる
- 弁護士免責文言は毎回必ず最後に記載する
- 外国法が準拠法の場合は「日本法との比較は困難。現地法律事務所への確認を推奨」と明示
- 感情的・道義的な話（「それは不誠実だ」等）には踏み込まず、法的リスクに絞る
