# カレンダー読み取りスキル（ブラウザ経由）

ChromeのGoogleカレンダーをブラウザ操作で読み取る。
読み取り専用。予定の作成・変更はユーザーが行う。

## 前提条件

- ChromeがGoogleアカウントにログイン済みであること
- `/browser` コマンドが有効であること

## 実行手順

### Step 1: 期間・条件を確認する

- 「今日」「今週」「来週」「〇月〇日」など期間を特定する
- 特定の会議名・参加者で絞り込む場合は条件を把握する

### Step 2: ブラウザでカレンダーを開く

1. `/browser` でブラウザを起動
2. `https://calendar.google.com` を開く
3. 対象期間のビューに移動する
4. 予定を読み取る

### Step 3: 結果を整理して提示する

**予定一覧の場合**:
```markdown
## {期間} のスケジュール

### {日付（曜日）}
- {時刻} ── {予定名}（{場所/会議URL}）
- {時刻} ── {予定名}

### {日付（曜日）}
- {時刻} ── {予定名}

**空き時間**: {空き時間帯をリスト}
```

**特定予定の検索結果**:
```markdown
## 「{検索キーワード}」の予定

- {日時}: {予定名}（{詳細}）
```

### Step 4: 関連する状況を提示する（オプション）

予定の内容からBacklogチケット・プロジェクト状況と紐付けて補足する：
（例：「この会議はプロジェクトAに関連しています。現在の状況: {status.md から}」）

## 注意事項

- カレンダーの予定を変更・削除する操作はしない（読み取り専用）
- 個人的な予定内容は要約のみ提示し、詳細をファイルに記録しない
- 複数のGoogleアカウントがある場合は、どのアカウントのカレンダーか確認する
- ブラウザ操作が失敗した場合はユーザーに状況を報告する
