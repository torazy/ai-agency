# 業務ルール（rules.md）

> 社内規程・手順・締め日・承認の流れ・使ってよい道具など、仕事の「決まりごと」。秘書は判断や作業の前提として引く
> （`python tools/recall.py find {語} --type rule`）。出典（規程名・URL・誰から聞いたか）と、最後に確かめた日を必ず書く。
> 案件だけの決まりごとは `memory/projects/{案件}/context/` に置く。経験から得た学びは `memory/insights.md`。
> 追加・更新は `python tools/mem.py rule add|set-state|confirm`（表を手で編集しない）。
> 確認日が古くなったルールは、毎朝の点検（`recall.py review`）が「今も有効か」を拾う。
